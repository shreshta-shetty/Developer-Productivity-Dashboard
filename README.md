# 🚀 DevTrack - Developer Productivity Dashboard

DevTrack is a simple productivity dashboard I built using HTML, CSS, and JavaScript.

The main idea behind this project is to have one place where I can manage my tasks, projects, and daily coding activity.

---

## ✨ What can you do with DevTrack?

- Add, edit, and delete tasks
- Mark tasks as completed
- Search for tasks
- Filter tasks by completed or pending
- Sort tasks by date, name, or status
- Add, edit, and delete projects
- Track weekly activity
- View basic productivity statistics
- Switch between light and dark mode
- Save tasks and projects using LocalStorage
- View a GitHub-style contribution calendar
- Get small notifications when actions are completed
- Use the dashboard on different screen sizes
